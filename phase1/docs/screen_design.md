# 画面設計メモ（ラフ）

## 画面一覧

| 画面 | パス | 説明 |
|---|---|---|
| トップ / アップロード | `/` | PDFアップロードとセッション一覧 |
| チャット | `/chat/[sessionId]` | 要約表示・質問応答 |

---

## コンポーネント一覧（予定）

| コンポーネント | 役割 |
|---|---|
| `FileUpload` | PDFドラッグ&ドロップ・選択 |
| `SummaryPanel` | 要約テキスト表示 |
| `ChatWindow` | メッセージ一覧表示 |
| `ChatInput` | テキスト入力・送信 |
| `CostBadge` | トークン数・概算コスト表示 |
| `SessionList` | 過去セッション一覧 |

---

## APIエンドポイント（予定）

| メソッド | パス | 役割 |
|---|---|---|
| POST | `/api/upload` | PDFアップロード・テキスト抽出・要約生成 |
| POST | `/api/chat` | 質問応答（Streaming） |
| GET | `/api/sessions` | セッション一覧取得 |
| GET | `/api/sessions/[id]` | セッション詳細・メッセージ履歴取得 |
