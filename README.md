# ROADTONEWSU

Main generated-AI application roadmap and implementation repository.

This repository is the primary place for building the AI application portfolio: PDF Q&A in Phase 1, RAG in Phase 2, and agent-style workflows in later phases.

## Portfolio Role

- Main AI app repository.
- New generated-AI app features should usually be added here instead of creating another similar repository.
- `phase1/` contains the current PDF summary and question-answering app built with Next.js, Supabase, and OpenAI-compatible APIs.

## Structure

- `genai_app_to_agent_roadmap.md`: roadmap from generated-AI app development toward AI agent engineering.
- `phase1/`: PDF summary and Q&A application.

## Related Repositories

- `Engineer_PU`: strategy, weekly operations, repository positioning, and publishing hub.
- `PDF_Read_analyzer`: Python PDF/RAG learning and comparison material.
